Overview

A DSNR object (Discovery System Normalized Record) is a simple data structure that you can use as a target resource when performing data normalization routines. A DNSR record consists of unique sections. A section is unique identified by it's name. Each section can hold many fields that store the actual values.

A DSNR object can be transformed into XML or JSON to allow easy integration into existing tools and workflows.

For example: If you normalize MARCXML data for use in a search engine you can use a DSNR object to store your normalized values.

def add(section_name, field_name, value)

def to_xml
  doc  = Ox::Document.new(version: "1.0")
  root = Ox::Element.new("dsnr")

  sections.each do |section|
    section_node = Ox::Element.new(section.name)

    section.fields.each do |field|
      field_node = Ox::Element.new(field.name)
      field_node << field.value
      section_node << field_node
    end

    root << section_node
  end

  doc << root

  Ox.dump(doc)
end
