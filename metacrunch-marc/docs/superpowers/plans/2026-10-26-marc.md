# metacrunch-marc Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn metacrunch-marcxml into metacrunch-marc: one record model and query API over MARCXML, ISO 2709 and
MARC-in-JSON, with a Reader that detects the format of each document and a Writer with `format:`.

**Architecture:** The record model (`Record`, `ControlField`, `DataField`, `Subfield`) stays as it is. Each format is
a module (`Marc::Xml`, `Marc::Iso2709`, `Marc::Json`) with `parse`, `each` and `each_raw`, an internal parser and an
internal serializer; all of them apply one value rule (`Marc::Values`). `Marc::Formats` tells the format of a
document from its first bytes; `Marc::Reader` (on `Metacrunch::Input`) and `Marc::Writer` (on `Metacrunch::Output`)
are the only files that need metacrunch.

**Tech Stack:** Ruby 4.0 with YJIT, Ox 2.14 (MARCXML), json 3.1 (part of Ruby), metacrunch 5 (branch `metacrunch-ng`),
Minitest, SimpleCov, RuboCop with rubocop-ubpb, ruby-marc 1.4 (tests only).

**Spec:** `docs/superpowers/specs/2026-10-25-marc-design.md`, amended in the commit of this plan (see "Spec
amendments" below). Read it with this plan.

## Review Focus

Inputs the spec implies but its tests would not meet; each has a test in the task named:

1. A pretty-printed MARC-in-JSON file (one object over many lines): every line fails, so the reader yields
   `InvalidRecord`s whose message says that MARC-in-JSON has one record per line and how to convert (Task 5,
   `test_a_pretty_printed_line_gets_a_hint`; Task 8, `test_a_pretty_printed_json_file`).
2. Bytes after the last ISO 2709 record that are not a record (a DOS end-of-file `0x1A`, a cut download): the records

   `test_bytes_after_the_last_iso2709_record`).
3. MARC-in-JSON with `\r\n` line ends and a last line without a line break: read as with `\n` (Task 5,
   `test_each_raw_takes_crlf_and_a_last_line_without_a_break`).
4. An ISO 2709 file that starts with a UTF-8 byte order mark: detected and read, not a broken first record (Task 3,
   `test_skips_a_byte_order_mark_at_the_start`; Task 8, `test_iso2709_after_a_byte_order_mark`).
5. A record read from MARCXML with a local tag (`852H`) or a two-character code, written as ISO 2709: in the sink the

## Spec amendments (made with this plan)

The plan's code was checked in a throwaway prototype (records of the benchmark: ISO 2709 parse 12.5 µs, write 6.2 µs,
byte-identical to ruby-marc's `to_marc`). It changed these points of the spec:

- 2, 5.2: `Iso2709::Splitter` becomes `Marc::Delimited`, which cuts input after a byte and also serves the lines of
  MARC-in-JSON.
- 5.2: a UTF-8 byte order mark at the start of an ISO 2709 input is skipped (detection skips it too).
- 3.4: `Record.from_h` transcodes Strings in other encodings (binary as UTF-8); `"subfields"` is required.
- 6.1, 6.2: `Json.parse(string)` reads one JSON object, also pretty-printed over several lines; a line that fails and
  is not a whole object gets a hint about one record per line.
- 8: the JSON array hint is `jq -c '.[]' in.json > out.jsonl`, generic like the MARC-8 hint.
- 11.2, 11.4: `local.xml` (tag `852H`, codes `as`, `dl`) gets no `.mrc` twin; its round trips skip ISO 2709.
- 1.3, 11.6: with the serialize step, MARCXML output has the same records (record Strings are not indented as the
  Writer indents them); ISO 2709 and MARC-in-JSON output stays byte-identical.

- [ ] **Step 4: Write `lib/metacrunch/marc/xml.rb`**

```ruby
# frozen_string_literal: true

require "stringio"

module Metacrunch
  module Marc
    # MARCXML, MARC 21 in XML: parsed with Ox (Xml::Parser), cut into record
    # strings without parsing (Xml::Splitter) and written by Record#to_xml
    # (Xml::Serializer).
    module Xml

      # The namespace of the MARC 21 XML schema.
      NAMESPACE = "http://www.loc.gov/MARC21/slim"

      # The start and the end of a collection, as the Writer writes them.
      HEADER = "<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n<collection xmlns=\"#{NAMESPACE}\">\n".freeze
      FOOTER = "</collection>\n"

      class << self

        # The one record in xml, a String with one <record>, bare or in a
        # <collection>. Raises ParseError for none or more than one.
        def parse(xml, normalize: nil)
          raise ArgumentError, "xml must be a String, got #{xml.class}" unless xml.is_a?(String)

          records = each(xml, normalize:).to_a
          raise ParseError, "no record found" if records.empty?
          if records.size > 1
            raise ParseError, "#{records.size} records found where one was expected (use Marc::Xml.each)"
          end

          records.first
        end

        # Yields every record of input: a String, or an object with
        # readpartial or read (a File, a Zlib::GzipReader, a pipe). Without a
        # block an Enumerator.
        def each(input, normalize: nil, &block)
          Marc.check_input(input)
          Marc.check_normalize(normalize)
          return enum_for(:each, input, normalize:) unless block

          Parser.run(source(input), normalize:, &block)
          nil
        end

        # Yields every record of input as a String from its start tag to its
        # end tag, without parsing it. Without a block an Enumerator.
        def each_raw(input, &block)
          Marc.check_input(input)
          return enum_for(:each_raw, input) unless block

          Splitter.new(input).each(&block)
          nil
        end

        private

        # Ox is superlinear on a String and a StringIO; both reach it through
        # readpartial.
        def source(input)
          case input
          when String then StringSource.new(input)
          when StringIO then IoSource.new(input)
          else input
          end
        end

      end

    end
  end
end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    # The rule of every parser and serializer for the leader, tags,
    # indicators, codes and values: valid UTF-8, and no character that XML
    # 1.0 cannot represent (control characters but tab and line breaks, and
    # two noncharacters). So whatever one format reads, the others can
    # write, and the separators of ISO 2709 never reach a value. Internal.
    module Values

      # Characters XML 1.0 cannot represent, also not as references: control
      # characters but tab and line breaks, and two noncharacters.
      CONTROL = /[\x00-\x08\x0B\x0C\x0E-\x1F]/
      NONCHARACTERS = ["\uFFFE", "\uFFFF"].freeze
      UNREPRESENTABLE = "cannot be represented in XML 1.0"

      module_function

      # The first character of string that XML 1.0 cannot represent, or nil.
      # Checks ASCII and non-ASCII apart; one regex with both is much slower.
      def unrepresentable(string)
        return string[CONTROL] if string.match?(CONTROL)
        return if string.ascii_only?

        NONCHARACTERS.find { string.include?(it) }
      end

      # What breaks the rule in string, a String in UTF-8, or nil.
      def problem(string)
        return "invalid UTF-8" unless string.valid_encoding?

        forbidden = unrepresentable(string)
        "#{forbidden.inspect} #{UNREPRESENTABLE}" if forbidden
      end

      # value as a parser keeps it: checked and, with normalize: :nfc, in NFC.
      # Strings in other encodings are taken as the serializers take them.
      # Raises ParseError "<place>: <problem>"; the block gives the place and
      # runs only on errors.
      def parsed(value, normalize)
        value = utf8(value) unless value.encoding == Encoding::UTF_8
        problem = problem(value)
        raise ParseError, "#{yield}: #{problem}" if problem
        return value if normalize.nil? || value.ascii_only?

        value.unicode_normalize(:nfc)
      end

      # value as a serializer writes it: a String in UTF-8 (nil is ""; other
      # objects give their to_s). Raises SerializeError "<place>: <problem>";
      # the block gives the place and runs only on errors.
      def serializable(value)
        string = value.to_s
        string = utf8(string) unless string.encoding == Encoding::UTF_8
        raise SerializeError, "#{yield}: invalid UTF-8 #{string.inspect}" unless string.valid_encoding?

        forbidden = unrepresentable(string)
        raise SerializeError, "#{yield}: #{forbidden.inspect} #{UNREPRESENTABLE}" if forbidden

        string
      end

      # Binary strings are taken as UTF-8; strings in other encodings are
      # transcoded, or taken as UTF-8 if they cannot be.
      def utf8(string)
        return string.dup.force_encoding(Encoding::UTF_8) if string.encoding == Encoding::BINARY

        string.encode(Encoding::UTF_8)
      rescue EncodingError
        string.dup.force_encoding(Encoding::UTF_8)
      end

      # "field 245 $a", with invalid bytes shown as escapes.
      def location(tag, code = nil)
        where = "field #{readable(tag)}"
        code ? "#{where} $#{readable(code)}" : where
      end

      def readable(value)
        string = value.to_s.dup.force_encoding(Encoding::UTF_8)
        string.scrub { |bytes| bytes.unpack("C*").map { format("\\x%02X", it) }.join }
      end

    end
  end
end
```

```ruby
# IO-like inputs that hand out their bytes in odd pieces, for the splitters.
module Inputs

  # Gives the input one byte per call, to cut every tag and terminator.
  class Trickle

    def initialize(string)
      @bytes = string.b
      @position = 0
    end

    def readpartial(_length)
      raise EOFError if @position >= @bytes.bytesize

      @position += 1
      @bytes.byteslice(@position - 1, 1)
    end

  end

  # Gives the input in chunks of a fixed size, whatever is asked for.
  class Chunked

    def initialize(string, size)
      @bytes = string.b
      @size = size
      @position = 0
    end

    def readpartial(_length)
      raise EOFError if @position >= @bytes.bytesize

      @position += @size
      @bytes.byteslice(@position - @size, @size)
    end

  end

  # Has only read, as some IO-like objects do.
  class ReadOnly

    def initialize(string)
      @io = StringIO.new(string)
    end

    def read(length) = @io.read(length)

  end

end
```

```ruby
# Builds ISO 2709 records byte by byte, so a test shows the defect it reads:
# lengths and starts are right, and numbers too large for their positions
# are nines, as the serializer writes them.
module Iso

  LEADER = "00000nam a2200000 c 4500"

  # A binary record from [tag, body] pairs; a body is the field without its
  # terminator, e.g. "10\x1FaTitle".
  def raw(*fields, leader: LEADER)
    directory = String.new(encoding: Encoding::BINARY)
    data = String.new(encoding: Encoding::BINARY)
    fields.each do |tag, body|
      body = "#{body}\x1E".b
      directory << tag.b << number(body.bytesize, 4) << number(data.bytesize, 5)
      data << body
    end
    record = leader.b << directory << "\x1E" << data << "\x1D"
    record[12, 5] = number(24 + directory.bytesize + 1, 5)
    record[0, 5] = number(record.bytesize, 5)
    record
  end

  # A record with a control field 001 and a 245.
  def book(id = "1") = raw(["001", id], ["245", "10\x1FaTitle\x1FbSub"])

  def number(value, digits) = value.to_s.size > digits ? "9" * digits : value.to_s.rjust(digits, "0")

end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    # Cuts input (a String, or an object with readpartial or read) into
    # binary pieces that end with a delimiter byte; the rest after the last
    # delimiter, if any, comes last. Searches go on where they stopped and
    # taken pieces are dropped once they exceed a chunk, so the time grows in
    # proportion to the input, however long a piece is. Internal.
    class Delimited

      CHUNK_SIZE = 65_536

      def initialize(input, delimiter)
        # A String is the buffer itself, with nothing more to read.
        @input = input.is_a?(String) ? nil : input
        @delimiter = delimiter
        @buffer = input.is_a?(String) ? input.b : String.new(encoding: Encoding::BINARY)
        # Where the next piece starts.
        @position = 0
        # Where the search for the delimiter goes on.
        @scan = 0
      end

      def each
        loop do
          if (piece = take)
            yield piece
          elsif !read_more?
            break
          end
        end
        yield slice(@buffer.bytesize) if @position < @buffer.bytesize
      end

      private

      # The next whole piece in the buffer, or nil.
      def take
        found = @buffer.byteindex(@delimiter, @scan)
        unless found
          @scan = @buffer.bytesize
          return
        end

        @scan = found + 1
        slice(found + 1)
      end

      def slice(to)
        piece = @buffer.byteslice(@position, to - @position)
        @position = to
        piece
      end

      # Appends the next chunk; false at the end of the input.
      def read_more?
        chunk = read
        return false unless chunk

        compact if @position > CHUNK_SIZE
        @buffer << (chunk.encoding == Encoding::BINARY ? chunk : chunk.b)
        true
      end

      def compact
        @buffer = @buffer.byteslice(@position, @buffer.bytesize - @position)
        @scan -= @position
        @position = 0
      end

      def read
        return unless @input

        chunk = @input.respond_to?(:readpartial) ? @input.readpartial(CHUNK_SIZE) : @input.read(CHUNK_SIZE)
        chunk unless chunk.nil? || chunk.empty?
      rescue EOFError
        nil
      end

    end
  end
end
```

```ruby
module Metacrunch
  module Marc
    # ISO 2709 ("binary MARC", .mrc) in UTF-8: records framed by the record
    # terminator and read by a parser that trusts the terminators, not the
    # lengths (Iso2709::Parser); written by Record#to_iso2709
    # (Iso2709::Serializer).
    module Iso2709

      RECORD_TERMINATOR = "\x1D"
      FIELD_TERMINATOR = "\x1E"
      SUBFIELD_DELIMITER = "\x1F"

      # Internal: the length of a leader, and the characters the common rule
      # forbids in data that holds field terminators and subfield delimiters.
      LEADER_LENGTH = 24
      FORBIDDEN = /[\x00-\x08\x0B\x0C\x0E-\x1D]/

      BOM = "\xEF\xBB\xBF".b
      # Bytes that are not skipped between records: all but space, tab, line
      # breaks and NUL.
      CONTENT = /[^ \t\r\n\0]/n
      private_constant :BOM, :CONTENT

      class << self

        # The one record in string. Raises ParseError for none or more than
        # one.
        def parse(string, normalize: nil)
          raise ArgumentError, "string must be a String, got #{string.class}" unless string.is_a?(String)

          Marc.check_normalize(normalize)
          raws = each_raw(string).to_a
          raise ParseError, "no record found" if raws.empty?
          if raws.size > 1
            raise ParseError, "#{raws.size} records found where one was expected (use Marc::Iso2709.each)"
          end

          Parser.parse(raws.first, normalize:)
        end

        # Yields every record of input: a String, or an object with
        # readpartial or read. Raises ParseError at the first record that
        # cannot be read. Without a block an Enumerator.
        def each(input, normalize: nil, &block)
          Marc.check_input(input)
          Marc.check_normalize(normalize)
          return enum_for(:each, input, normalize:) unless block

          each_raw(input) { |raw| yield Parser.parse(raw, normalize:) }
        end

        # Yields every record of input as a String in UTF-8 (possibly
        # invalid) up to and including its record terminator, without
        # parsing it. Space, tab, line breaks and NUL between records and a
        # byte order mark at the start are skipped; bytes at the end without
        # a terminator are yielded as they are and fail when parsed. Without
        # a block an Enumerator.
        def each_raw(input)
          Marc.check_input(input)
          return enum_for(:each_raw, input) unless block_given?

          first = true
          Delimited.new(input, RECORD_TERMINATOR.b).each do |piece|
            piece = piece.delete_prefix(BOM) if first
            first = false
            start = piece.index(CONTENT)
            next unless start

            piece = piece.byteslice(start, piece.bytesize - start) if start.positive?
            yield piece.force_encoding(Encoding::UTF_8)
          end
          nil
        end

      end

    end
  end
end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    module Iso2709
      # Builds a Record from one ISO 2709 record that ends with its record
      # terminator. The terminators decide, not the lengths: the directory
      # runs to the first field terminator, the data is split on field
      # terminators, and a field with a subfield delimiter is a data field.
      # Record length, base address and field lengths are not used; starts
      # must not decrease, so data in another order than the directory fails
      # instead of pairing tags with the wrong data. Internal.
      class Parser

        ENTRY_LENGTH = 12
        RECORD_END = RECORD_TERMINATOR.b
        FIELD_END = FIELD_TERMINATOR.b
        DELIMITER = SUBFIELD_DELIMITER.b
        DIGITS = "0-9"
        MARC8 = "leader/09 says MARC-8; convert the file to UTF-8 first, e.g. " \
                "yaz-marcdump -f MARC-8 -t UTF-8 -o marc -l 9=97 in.mrc > out.mrc"

        def self.parse(raw, normalize:) = new(raw, normalize).record

        def initialize(raw, normalize)
          @raw = raw.b
          @normalize = normalize
        end

        # Checks the data of all fields at once; only if that fails, field by
        # field, to name the place.
        def record
          raise ParseError, "the input ended inside a record" unless @raw.end_with?(RECORD_END)

          @leader = leader
          tags, data_start = directory
          data = @raw.byteslice(data_start, @raw.bytesize - data_start - 1)
          pieces = pieces(data, tags.size)
          clean = clean?(data)
          fields = Array.new(tags.size) { field(tags[it], pieces[it], clean) }
          locate(fields) unless clean
          Record.new(leader: @leader, fields:)
        end

        private

        def leader
          if @raw.bytesize <= LEADER_LENGTH
            raise ParseError, "the record has #{@raw.bytesize} bytes, fewer than its leader of 24 and the terminator"
          end

          leader = @raw.byteslice(0, LEADER_LENGTH)
          unless leader.ascii_only?
            raise ParseError, "leader: an ISO 2709 leader has 24 ASCII characters, got #{leader.inspect}"
          end

          Values.parsed(leader.force_encoding(Encoding::UTF_8), nil) { "leader" }
        end

        # The tags of the directory and where the data starts.
        def directory
          directory_end = @raw.index(FIELD_END, LEADER_LENGTH)
          raise ParseError, "the directory has no end (no field terminator)" unless directory_end

          length = directory_end - LEADER_LENGTH
          unless (length % ENTRY_LENGTH).zero?
            raise ParseError, "the directory has #{length} bytes, not a multiple of #{ENTRY_LENGTH}"
          end

          directory = @raw.byteslice(LEADER_LENGTH, length)
          clean = directory.ascii_only? && !directory.match?(Values::CONTROL)
          previous = 0
          tags = Array.new(length / ENTRY_LENGTH) do |index|
            tag = directory.byteslice(index * ENTRY_LENGTH, 3)
            check_tag(tag, index + 1) unless clean
            tag.force_encoding(Encoding::UTF_8)
            previous = start(directory.byteslice((index * ENTRY_LENGTH) + 7, 5), previous, index + 1, tag)
            tag
          end
          [tags, directory_end + 1]
        end

        def check_tag(tag, number)
          unless tag.ascii_only?
            raise ParseError, "directory entry #{number}: the tag #{tag.inspect} is not 3 ASCII characters"
          end

          problem = Values.problem(tag.dup.force_encoding(Encoding::UTF_8))
          raise ParseError, "directory entry #{number}: the tag #{problem}" if problem
        end

        # The start of a directory entry as a number.
        def start(text, previous, number, tag)
          unless text.count(DIGITS) == 5
            raise ParseError, "directory entry #{number} (#{tag}): the start #{text.inspect} is not 5 digits"
          end

          start = text.to_i
          if start < previous
            raise ParseError, "directory entry #{number} (#{tag}): the start #{start} is less than the start " \
                              "before it (#{previous})"
          end

          start
        end

        # The fields of data; a last field terminator may be missing.
        def pieces(data, count)
          pieces = data.split(FIELD_END, -1)
          pieces.pop if data.end_with?(FIELD_END)
          return pieces if pieces.size == count

          raise ParseError, "the directory has #{count} entries, the data #{pieces.size} fields"
        end

        # Whether all fields keep to the common rule (the separators aside).
        def clean?(data)
          text = data.dup.force_encoding(Encoding::UTF_8)
          text.valid_encoding? && !text.match?(FORBIDDEN) &&
            (text.ascii_only? || Values::NONCHARACTERS.none? { text.include?(it) })
        end

        def field(tag, piece, clean)
          delimiter = piece.index(DELIMITER)
          return ControlField.new(tag, value(piece.force_encoding(Encoding::UTF_8), clean)) unless delimiter

          indicators = piece.byteslice(0, delimiter).force_encoding(Encoding::UTF_8)
          unless indicators.length == 2
            raise ParseError,
                  "field #{Values.readable(tag)}: ISO 2709 indicators are 2 characters, got #{indicators.inspect}"
          end

          parts = piece.byteslice(delimiter + 1, piece.bytesize - delimiter - 1).split(DELIMITER, -1)
          subfields = parts.map do |part|
            raise ParseError, "field #{Values.readable(tag)}: a subfield without a code" if part.empty?

            part.force_encoding(Encoding::UTF_8)
            Subfield.new(part[0], value(part[1..], clean))
          end
          DataField.new(tag, indicators[0], indicators[1], subfields)
        end

        # A value, in NFC with normalize: :nfc. Values of a record that is
        # not clean are left as they are; locate raises for it.
        def value(text, clean)
          return text unless clean && @normalize && !text.ascii_only?

          text.unicode_normalize(:nfc)
        end

        # Raises for the first indicators, code or value that breaks the
        # common rule.
        def locate(fields)
          fields.each do |field|
            next check(field.value) { Values.location(field.tag) } if field.is_a?(ControlField)

            check(field.ind1 + field.ind2) { "#{Values.location(field.tag)} indicators" }
            field.subfields.each do |subfield|
              check(subfield.code) { Values.location(field.tag, subfield.code) }
              check(subfield.value) { Values.location(field.tag, subfield.code) }
            end
          end
        end

        def check(text)
          problem = Values.problem(text)
          return unless problem

          problem = "#{problem}; #{MARC8}" if problem == "invalid UTF-8" && @leader[9] == " "
          raise ParseError, "#{yield}: #{problem}"
        end

      end
    end
  end
end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    module Iso2709
      # Writes a Record as ISO 2709 (Record#to_iso2709): leader, directory,
      # the fields in record order, the record terminator. Lengths and starts
      # count UTF-8 bytes. The leader gets the record length, "a" at 09
      # (UTF-8), "22" at 10-11, the base address and "450" at 20-22; the
      # other positions are copied. Internal.
      module Serializer

        # The leader of a record without one, before the computed positions.
        LEADER = "00000    a2200000   4500"
        MAX_FIELD = 9_999
        MAX_RECORD = 99_999
        OVERSIZE = [:error, :allow].freeze
        ANYWAY = "(oversize: :allow writes it anyway)"
        SEPARATORS = FIELD_TERMINATOR + SUBFIELD_DELIMITER

        module_function

        # Values are appended as they are and checked all at once; only if
        # that fails, value by value, to name the place.
        def record(record, oversize:)
          unless OVERSIZE.include?(oversize)
            raise ArgumentError, "oversize must be :error or :allow, got #{oversize.inspect}"
          end

          leader = leader(record.leader)
          directory = String.new(encoding: Encoding::UTF_8)
          data = String.new(encoding: Encoding::UTF_8)
          separators = 0
          record.fields.each do |field|
            start = data.bytesize
            tag = tag(field.tag)
            separators += field.is_a?(DataField) ? data_field(data, field) : control_field(data, field)
            length = data.bytesize - start
            check_field_size(tag, length, oversize)
            directory << tag << number(length, 4) << number(start, 5)
          end
          locate(record) unless clean?(directory, data, separators)
          # The directory ends with a field terminator, the record with a
          # record terminator.
          base = LEADER_LENGTH + directory.bytesize + 1
          size = base + data.bytesize + 1
          check_record_size(size, oversize)
          leader[0, 5] = number(size, 5)
          leader[9] = "a"
          leader[10, 2] = "22"
          leader[12, 5] = number(base, 5)
          leader[20, 3] = "450"
          leader << directory << FIELD_TERMINATOR << data << RECORD_TERMINATOR
        end

        # A copy of the leader to fill in.
        def leader(leader)
          return LEADER.dup if leader.nil?

          string = Values.serializable(leader) { "leader" }
          return string.dup if string.bytesize == LEADER_LENGTH && string.ascii_only?

          raise SerializeError, "leader: an ISO 2709 leader has 24 ASCII characters, got #{string.inspect}"
        end

        def tag(tag)
          return tag if tag.is_a?(String) && tag.bytesize == 3 && tag.ascii_only?

          string = Values.serializable(tag) { Values.location(tag) }
          return string if string.bytesize == 3 && string.ascii_only?

          raise SerializeError, "#{Values.location(tag)}: an ISO 2709 tag has 3 ASCII characters"
        end

        # Appends the field; returns the number of separators appended.
        def control_field(data, field)
          data << text(field.value) { Values.location(field.tag) } << FIELD_TERMINATOR
          1
        end

        # Appends the field; returns the number of separators appended.
        def data_field(data, field)
          subfields = field.subfields
          if subfields.empty?
            raise SerializeError, "#{Values.location(field.tag)}: an ISO 2709 data field needs a subfield; " \
                                  "without one it would be read back as a control field"
          end

          data << character(field.ind1, "indicator") { Values.location(field.tag) }
          data << character(field.ind2, "indicator") { Values.location(field.tag) }
          subfields.each do |subfield|
            code = character(subfield.code, "subfield code") { Values.location(field.tag, subfield.code) }
            data << SUBFIELD_DELIMITER << code << text(subfield.value) { Values.location(field.tag, subfield.code) }
          end
          data << FIELD_TERMINATOR
          subfields.size + 1
        end

        # A UTF-8 String as it is (clean? checks it); others through Values.
        def text(value, &)
          return value if value.is_a?(String) && value.encoding == Encoding::UTF_8

          Values.serializable(value, &)
        end

        # An indicator or a code: one ASCII character.
        def character(value, name, &)
          return value if value.is_a?(String) && value.bytesize == 1 && value.ascii_only?

          string = Values.serializable(value, &)
          return string if string.bytesize == 1 && string.ascii_only?

          raise SerializeError, "#{yield}: an ISO 2709 #{name} is 1 ASCII character, got #{string.inspect}"
        end

        # Whether tags and data keep to the common rule: data with exactly the
        # separators appended, and none of the forbidden characters.
        def clean?(directory, data, separators)
          !directory.match?(Values::CONTROL) && data.valid_encoding? && !data.match?(FORBIDDEN) &&
            data.count(SEPARATORS) == separators &&
            (data.ascii_only? || Values::NONCHARACTERS.none? { data.include?(it) })
        end

        # Raises for the first tag, indicator, code or value that breaks the
        # common rule.
        def locate(record)
          record.fields.each do |field|
            Values.serializable(field.tag) { Values.location(field.tag) }
            next Values.serializable(field.value) { Values.location(field.tag) } if field.is_a?(ControlField)

            Values.serializable(field.ind1) { Values.location(field.tag) }
            Values.serializable(field.ind2) { Values.location(field.tag) }
            field.subfields.each do |subfield|
              Values.serializable(subfield.code) { Values.location(field.tag, subfield.code) }
              Values.serializable(subfield.value) { Values.location(field.tag, subfield.code) }
            end
          end
        end

        def check_field_size(tag, length, oversize)
          return if length <= MAX_FIELD || oversize == :allow

          raise SerializeError, "field #{tag} has #{length} bytes, ISO 2709 allows #{MAX_FIELD} #{ANYWAY}"
        end

        def check_record_size(size, oversize)
          return if size <= MAX_RECORD || oversize == :allow

          raise SerializeError, "the record has #{size} bytes, ISO 2709 allows #{MAX_RECORD} #{ANYWAY}"
        end

        # value with leading zeros, or all nines if it does not fit.
        def number(value, digits)
          string = value.to_s
          string.bytesize > digits ? "9" * digits : string.rjust(digits, "0")
        end

      end
    end
  end
end
```

```ruby
# frozen_string_literal: true

require "json"

module Metacrunch
  module Marc
    # MARC-in-JSON (https://github.com/marc-in-json/marc-in-json): Record#to_h
    # as JSON, one record per line (JSON Lines). Read by Json::Parser,
    # written by Json::Serializer.
    module Json

      NEWLINE = "\n".b
      BOM = "\xEF\xBB\xBF".b
      private_constant :NEWLINE, :BOM

      class << self

        # The one record in string: one JSON object, also over several lines.
        # Raises ParseError for anything else.
        def parse(string, normalize: nil)
          raise ArgumentError, "string must be a String, got #{string.class}" unless string.is_a?(String)

          Marc.check_normalize(normalize)
          Parser.line(string, normalize:)
        end

        # Yields the record of every line of input: a String, or an object
        # with readpartial or read. Raises ParseError at the first line that
        # cannot be read. Without a block an Enumerator.
        def each(input, normalize: nil, &block)
          Marc.check_input(input)
          Marc.check_normalize(normalize)
          return enum_for(:each, input, normalize:) unless block

          each_raw(input) { |line| yield Parser.line(line, normalize:) }
        end

        # Yields every line of input that is not blank as a String in UTF-8
        # (possibly invalid), without its line break and without a byte
        # order mark at its start. Without a block an Enumerator.
        def each_raw(input)
          Marc.check_input(input)
          return enum_for(:each_raw, input) unless block_given?

          Delimited.new(input, NEWLINE).each do |piece|
            line = piece.chomp
            line.delete_prefix!(BOM)
            yield line.force_encoding(Encoding::UTF_8) unless line.strip.empty?
          end
          nil
        end

      end

    end
  end
end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    module Json
      # Builds Records from MARC-in-JSON: lines of JSON (Json.parse, .each)
      # and Hashes as Record#to_h returns them (Record.from_h). The shape is
      # strict: keys are Strings, a field has one key (its tag), a data field
      # has "ind1", "ind2" (missing or nil is " ") and "subfields". Every
      # problem raises ParseError with the path to it, e.g. "fields[3] (245)
      # subfields[0]: a value must be a String, got 12". Internal.
      class Parser

        RECORD_KEYS = ["leader", "fields"].freeze
        DATA_FIELD_KEYS = ["ind1", "ind2", "subfields"].freeze
        ONE_PER_LINE = "MARC-in-JSON has one record per line; jq -c . in.json > out.jsonl converts pretty-printed JSON"

        # The record of one JSON object in line; a byte order mark at its
        # start is skipped.
        def self.line(line, normalize:)
          bytes = line.b
          bytes.delete_prefix!(BOM)
          raise ParseError, "no record found" if bytes.strip.empty?

          # JSON takes invalid UTF-8 inside strings, so it is checked first.
          text = bytes.force_encoding(Encoding::UTF_8)
          raise ParseError, "invalid UTF-8" unless text.valid_encoding?

          new(normalize).record(json(text))
        end

        # The Hash of text. Duplicate keys raise (json 3). A line that is not
        # a whole object, as in a pretty-printed file, gets a hint.
        def self.json(text)
          value = JSON.parse(text)
          return value if value.is_a?(Hash)

          raise ParseError, "a record must be a JSON object, got #{short(value)}"
        rescue JSON::ParserError => e
          stripped = text.strip
          whole = stripped.start_with?("{") && stripped.end_with?("}")
          raise ParseError, whole ? e.message : "#{e.message} (#{ONE_PER_LINE})"
        end

        # value for a message, cut after 40 characters.
        def self.short(value)
          text = value.inspect
          text.length > 40 ? "#{text[0, 37]}..." : text
        end

        def initialize(normalize)
          @normalize = normalize
        end

        def record(hash)
          raise ParseError, "a record must be a Hash, got #{short(hash)}" unless hash.is_a?(Hash)

          unknown = hash.each_key.find { !RECORD_KEYS.include?(it) }
          raise ParseError, "unknown key #{unknown.inspect}; a record has \"leader\" and \"fields\"" if unknown

          fields = hash.fetch("fields") { raise ParseError, "a record needs \"fields\"" }
          raise ParseError, "fields: must be an Array, got #{short(fields)}" unless fields.is_a?(Array)

          leader = hash["leader"]
          leader = value(leader, "leader") unless leader.nil?
          Record.new(leader:, fields: fields.each_with_index.map { |field, index| field(field, "fields[#{index}]") })
        end

        private

        def field(field, path)
          unless field.is_a?(Hash) && field.size == 1
            raise ParseError, "#{path}: a field must be an object with one key, its tag, got #{short(field)}"
          end

          tag, content = field.first
          tag = name(tag, path, "a tag")
          path = "#{path} (#{Values.readable(tag)})"
          case content
          when String then ControlField.new(tag, value(content, path))
          when Hash then data_field(tag, content, path)
          else
            raise ParseError, "#{path}: a field must be a String (a control field) or an object (a data field), " \
                              "got #{short(content)}"
          end
        end

        def data_field(tag, hash, path)
          unknown = hash.each_key.find { !DATA_FIELD_KEYS.include?(it) }
          if unknown
            raise ParseError, "#{path}: unknown key #{unknown.inspect}; a data field has \"ind1\", \"ind2\" and " \
                              "\"subfields\""
          end

          subfields = hash.fetch("subfields") { raise ParseError, "#{path}: a data field needs \"subfields\"" }
          raise ParseError, "#{path} subfields: must be an Array, got #{short(subfields)}" unless subfields.is_a?(Array)

          subfields = subfields.each_with_index.map do |subfield, index|
            subfield(subfield, "#{path} subfields[#{index}]")
          end
          DataField.new(tag, indicator(hash["ind1"], "#{path} ind1"), indicator(hash["ind2"], "#{path} ind2"),
                        subfields)
        end

        def indicator(value, path) = value.nil? ? DataField::BLANK : name(value, path, "an indicator")

        def subfield(subfield, path)
          unless subfield.is_a?(Hash) && subfield.size == 1
            raise ParseError, "#{path}: a subfield must be an object with one key, its code, got #{short(subfield)}"
          end

          code, content = subfield.first
          Subfield.new(name(code, path, "a code"), value(content, path))
        end

        # A tag, an indicator or a code: a String under the common rule.
        def name(name, path, kind)
          raise ParseError, "#{path}: #{kind} must be a String, got #{short(name)}" unless name.is_a?(String)

          Values.parsed(name, nil) { path }
        end

        # A leader or a value: a String under the common rule, normalized
        # with normalize: :nfc.
        def value(value, path)
          raise ParseError, "#{path}: a value must be a String, got #{short(value)}" unless value.is_a?(String)

          Values.parsed(value, @normalize) { path }
        end

        def short(value) = Parser.short(value)

      end
    end
  end
end
```

```ruby
module Metacrunch
  module Marc
    module Json
      # Writes a Record as one line of MARC-in-JSON: JSON.generate of to_h
      # and "\n", with every String checked by the common rule first, so a
      # character that XML cannot represent raises although JSON could
      # escape it. The type is dropped. Internal.
      module Serializer

        module_function

        def record(record)
          hash = {}
          hash["leader"] = Values.serializable(record.leader) { "leader" } if record.leader
          hash["fields"] = record.fields.map { field(it) }
          "#{JSON.generate(hash)}\n"
        end

        def field(field)
          tag = Values.serializable(field.tag) { Values.location(field.tag) }
          return {tag => Values.serializable(field.value) { Values.location(field.tag) }} if field.is_a?(ControlField)

          subfields = field.subfields.map do |subfield|
            code = Values.serializable(subfield.code) { Values.location(field.tag, subfield.code) }
            {code => Values.serializable(subfield.value) { Values.location(field.tag, subfield.code) }}
          end
          {tag => {"ind1" => Values.serializable(field.ind1) { Values.location(field.tag) },
                   "ind2" => Values.serializable(field.ind2) { Values.location(field.tag) },
                   "subfields" => subfields}}
        end

      end
    end
  end
```

```ruby
# frozen_string_literal: true

module Metacrunch
  module Marc
    # Tells the format of a document from its first bytes, after a UTF-8 byte
    # order mark and after space, tab, line breaks and NUL: "<" is MARCXML,
    # "{" MARC-in-JSON, five digits at 0-4 and at 12-16 (record length and
    # base address) ISO 2709, "[" a JSON array. The base address keeps a CSV
    # file that starts with a number from being taken for ISO 2709. Internal.
    module Formats

      # Detection looks at the first WINDOW bytes, and at twice as many
      # while it sees only bytes it skips.
      WINDOW = 64
      BOM = "\xEF\xBB\xBF".b
      CONTENT = /[^ \t\r\n\0]/n
      ISO2709 = /\A\d{5}.{7}\d{5}/mn
      ISO2709_START = 17
      EXCERPT = 16

      module_function

      # The format of a document and the bytes seen, [format, head]: format
      # is :xml, :iso2709, :json, :array, :none (nothing but skipped bytes)
      # or :unknown. The block gives the first length bytes of the document,
      # fewer at its end.
      def detect
        window = WINDOW
        loop do
          head = yield(window).b
          format = format(head, complete: head.bytesize < window)
          return [format, head] if format

          window *= 2
        end
      end

      # The format of head; nil if more bytes follow (complete: false) and
      # head does not tell yet.
      def format(head, complete:)
        start = start(head)
        return complete ? :none : nil unless start

        case head.getbyte(start)
        when 0x3C then :xml
        when 0x7B then :json
        when 0x5B then :array
        when 0x30..0x39 then iso2709(head, start, complete)
        else :unknown
        end
      end

      # The module that reads format; Json also for :array, whose parse
      # explains why it cannot.
      def library(format)
        case format
        when :xml then Xml
        when :iso2709 then Iso2709
        else Json
        end
      end

      # The message for a document of format :unknown.
      def unknown(head)
        excerpt = head.byteslice(start(head) || 0, EXCERPT)
        "neither MARCXML, ISO 2709 nor MARC-in-JSON: it starts with #{excerpt.inspect}"
      end

      def iso2709(head, start, complete)
        return :iso2709 if head.byteslice(start, ISO2709_START).match?(ISO2709)
        return if !complete && head.bytesize - start < ISO2709_START

        :unknown
      end

      # Where the content starts, after a byte order mark and skipped bytes.
      def start(head) = head.index(CONTENT, head.start_with?(BOM) ? BOM.bytesize : 0)

    end
  end
end
```

```ruby
# frozen_string_literal: true

require "metacrunch"

module Metacrunch
  module Marc
    # A metacrunch source: reads MARCXML, ISO 2709 and MARC-in-JSON from what
    # Metacrunch::Input reads (paths, "-" for stdin, IOs or an Array of them;
    # gzip and tar are unpacked whatever their names). The format of each
    # document is told by its first bytes (see Formats), so inputs may mix
    # formats. Yields a Record per record, or with parse: false the record
    # as a String in its format, which is cheaper to send to workers. A
    # record that cannot be parsed is yielded as Metacrunch::InvalidRecord; a
    # document in another format raises Metacrunch::InputError.
    class Reader

      ARRAY = "is a JSON array of records; convert it to one record per line first, e.g. " \
              "jq -c '.[]' in.json > out.jsonl"

      # targets: what Metacrunch::Input takes. IOs are never closed.
      def initialize(targets, parse: true, normalize: nil)
        @input = Metacrunch::Input.new(targets)
        Marc.check_normalize(normalize)
        if normalize && !parse
          raise ArgumentError, "normalize: needs parse: true; with parse: false normalize in the step that parses: " \
                               "Metacrunch::Marc.parse(raw, normalize: :nfc)"
        end
        @parse = parse
        @normalize = normalize
      end

      # Without a block an Enumerator.
      def each(&)
        return enum_for(:each) unless block_given?

        @input.each_document do |stream, name|
          format = format(stream, name)
          read(Formats.library(format), stream, &) if format
        end
      end

      # The share of the input read so far; see Metacrunch::Input#progress.
      def progress = @input.progress

      private

      # The format of a document, or nil for one without data.
      def format(stream, name)
        format, head = Formats.detect { stream.peek(it) }
        case format
        when :none then nil
        when :array then raise Metacrunch::InputError, "#{name}: #{ARRAY}"
        when :unknown then raise Metacrunch::InputError, "#{name}: is #{Formats.unknown(head)}"
        else format
        end
      end

      def read(library, stream)
        library.each_raw(stream) { |raw| yield(@parse ? record(library, raw) : raw) }
      end

      def record(library, raw)
        library.parse(raw, normalize: @normalize)
      rescue ParseError => e
        Metacrunch::InvalidRecord.new(raw:, error: e)
      end

    end
  end
end
```

```ruby
# frozen_string_literal: true

require "metacrunch"

module Metacrunch
  module Marc
    # A metacrunch sink: writes records as MARCXML, ISO 2709 or MARC-in-JSON
    # to what Metacrunch::Output takes: a file (.gz compressed), stdout ("-")
    # or an IO. MARCXML is one <collection>, whose end close writes also
    # after an aborted run, so the output stays well-formed; ISO 2709 records
    # follow each other; MARC-in-JSON has one record per line.
    class Writer

      FORMATS = [:xml, :iso2709, :json].freeze
      OVERSIZE = [nil, :error, :allow].freeze
      NAMES = {xml: "MARCXML", iso2709: "ISO 2709", json: "MARC-in-JSON"}.freeze

      # Strings written as they are, e.g. serialized in a worker: a record
      # element (any prefix), an ISO 2709 record, one line of MARC-in-JSON.
      # Matched as binary, since a regexp raises on invalid UTF-8.
      XML_RECORD = %r{\A\s*<(?:[A-Za-z_][\w.-]*:)?record[\s>/]}n
      ISO2709_RECORD = /\A\d{5}/n
      JSON_RECORD = /\A\s*\{[^\n]*\n?\z/n

      # format: :xml, :iso2709 or :json. oversize: (ISO 2709 only) :error,
      # the default, or :allow; see Record#to_iso2709.
      def initialize(target, format:, oversize: nil)
        unless FORMATS.include?(format)
          raise ArgumentError, "format must be :xml, :iso2709 or :json, got #{format.inspect}"
        end
        unless OVERSIZE.include?(oversize)
          raise ArgumentError, "oversize must be :error or :allow, got #{oversize.inspect}"
        end
        raise ArgumentError, "oversize: is for format: :iso2709 only" if oversize && format != :iso2709

        @output = Metacrunch::Output.new(target)
        @format = format
        @oversize = oversize || :error
        @open = false
      end

      def open(_context)
        @output.open
        @open = true
        @output.write(Xml::HEADER) if @format == :xml
      end

      def write(record, ctx)
        @output.write(serialize(record, ctx))
      end

      def write_batch(records, ctxs)
        @output.write(records.zip(ctxs).map { |record, ctx| serialize(record, ctx) }.join)
      end

      # Writes the end of a MARCXML collection, also after an aborted run,
      # and closes the output. Does nothing the second time.
      def close
        return unless @open

        @open = false
        @output.write(Xml::FOOTER) if @format == :xml
      ensure
        @output.close
      end

      private

      # A Record is serialized here; a String of the format (serialized in a
      # worker, cheaper to send) is written as it is.
      def serialize(record, ctx)
        case record
        when Record then serialize_record(record)
        when String then string(record, ctx)
        else
          raise Metacrunch::Error,
                "record at position #{ctx.position} is not a Metacrunch::Marc::Record (#{record.class})"
        end
      rescue SerializeError => e
        raise Metacrunch::Error,
              "record at position #{ctx.position} cannot be written as #{NAMES[@format]}: #{e.message}"
      end

      def serialize_record(record)
        case @format
        when :xml then Xml::Serializer.record(record, namespace: false, indent: "  ")
        when :iso2709 then Iso2709::Serializer.record(record, oversize: @oversize)
        else Json::Serializer.record(record)
        end
      end

      def string(string, ctx)
        bytes = string.b
        case @format
        when :xml
          bytes.match?(XML_RECORD) ? line(string) : refuse(ctx, "a <record> element")
        when :iso2709
          iso2709 = bytes.match?(ISO2709_RECORD) && bytes.end_with?(Iso2709::RECORD_TERMINATOR)
          iso2709 ? string : refuse(ctx, "an ISO 2709 record")
        else
          bytes.match?(JSON_RECORD) ? line(string) : refuse(ctx, "one line of MARC-in-JSON")
        end
      end

      def line(string) = string.end_with?("\n") ? string : "#{string}\n"

      def refuse(ctx, kind)
        raise Metacrunch::Error, "record at position #{ctx.position} is a String but not #{kind}"
      end

    end
  end
end
```

````markdown
## Records

A `Metacrunch::Marc::Record` has a `leader` (a String or nil), a `type` (the `type` attribute of a MARCXML
`<record>`, e.g. `"Bibliographic"`, or nil) and `fields`, a frozen Array of `ControlField`s and `DataField`s in record
order. A `DataField` has a `tag`, two indicators (`ind1`, `ind2`; blank is `" "`) and `subfields`, an Array of
`Subfield`s with a `code` and a `value`. Tags and codes are Strings and are not checked, so local tags such as `852H`
and codes such as `as` work in the formats that can hold them (see [Formats](#formats)). The tag of a field is fixed.

### Output

- `record.to_xml` returns the record as MARCXML; `namespace: false` leaves out `xmlns`.
- `record.to_iso2709` returns it as ISO 2709, a String in UTF-8 (see [ISO 2709](#iso-2709)).
- `record.to_h` returns MARC-in-JSON: `{"leader" => "...", "fields" => [{"001" => "..."}, {"245" => {"ind1" => "1",
  "ind2" => "0", "subfields" => [{"a" => "..."}]}}]}`; `Metacrunch::Marc::Record.from_h(hash)` builds a record from
  such a Hash.
- `record.to_s` and `inspect` show one line per field as MarcEdit does (`=245  10$aTitle$bSubtitle`), so records are
  readable in `metacrunch trace` and in test failures.

## Formats

Each format has the same three functions:

```ruby
Metacrunch::Marc::Xml.parse(string)                    # exactly one record from a String
Metacrunch::Marc::Xml.each(io_or_string) { ... }       # every record, streaming
Metacrunch::Marc::Xml.each_raw(io_or_string) { ... }   # every record as a String, without parsing it
# the same for Metacrunch::Marc::Iso2709 and Metacrunch::Marc::Json

Metacrunch::Marc.parse(string)                         # one record, in the format its first bytes show
```

`each` and `each_raw` read Strings and IO-like objects (files, `StringIO`, `Zlib::GzipReader`, pipes); without a block
they return an Enumerator. They read in chunks, so the time grows in proportion to the input. `parse` raises
`Metacrunch::Marc::ParseError` for no record or several, and `each` at the first record it cannot read (the
[Reader](#reader) makes such a record a failure of its own). With `normalize: :nfc` the leader and the values are
normalized to Unicode NFC (some systems export decomposed characters); by default they are left as they are.

All parsers and serializers keep to one rule, so whatever one format reads, the others can write: the leader, tags,
indicators, codes and values are valid UTF-8 and contain no character that XML 1.0 cannot represent (control
characters other than tab and line breaks, U+FFFE and U+FFFF). Parsers raise `ParseError` and serializers
`Metacrunch::Marc::SerializeError`, naming the field: `field 245 $a: "\u0001" cannot be represented in XML 1.0`.
Serializers transcode Strings in other encodings and take binary Strings as UTF-8.

What each format can hold:

| | MARCXML | ISO 2709 | MARC-in-JSON |
|---|---|---|---|
| Tags | any | 3 ASCII characters | any |
| Indicators and codes | any | 1 ASCII character | any |
| Data field without subfields | yes | no (it would be read back as a control field) | yes |
| `type` | yes | no | no |
| Size | no limit | 9,999 bytes per field, 99,999 per record | no limit |

### MARCXML

Parsing takes about 28 µs per record of 3 KB in [`bench/parse.rb`](bench/parse.rb) (Ruby 4.0 with YJIT on an arm64
Mac); the time grows with the size of the records, by about 9 µs per KB. The parser keeps what the data says:

- whitespace at the start, at the end and inside values, and line breaks (XML itself turns `\r\n` into `\n`);
- the order of fields and subfields, repeated control fields, empty subfields;
- CDATA, entities, and values interrupted by comments;
- elements with a namespace prefix (`<marc:record>`), the `type` attribute, and a leader anywhere in the record.

A missing or empty indicator becomes `" "`. `ParseError` reports input that is not well-formed (with `line` and
`column`), input that ends inside a record, names and attributes that are not valid UTF-8 (MARCXML is UTF-8), and
values that break the rule above, also as references such as `&#31;`. Several records without a `<collection>` around
them are not well-formed XML for `each`; `each_raw` and the Reader read them. Ox, the XML parser underneath, does not
validate and accepts some input that is not well-formed; a reference `&#0;`, which XML does not allow, cuts the value
off there.

`each_raw` cuts the input at the end tags of the records; an end tag inside a CDATA section or a comment cuts a record
there. Elements are matched by their local name, whatever their namespace. Formats that wrap MARCXML in an element of
their own called `record`, such as OAI-PMH responses (`ListRecords`), are therefore not read correctly yet; take the
MARC records out of the wrapper first.

### ISO 2709

ISO 2709 is read and written in UTF-8. Parsing takes about 13 µs and writing about 6 µs per record in
`bench/parse.rb` (records of 3 KB as MARCXML are 1.1 KB as ISO 2709).

Reading trusts the terminators, not the numbers, as yaz-marcdump and MARC4J's permissive reader do:

- A record runs to its record terminator. The record length, the base address and the field lengths are not used, so
  records with wrong lengths, with lengths counted in characters, and records over 99,999 bytes with `99999` or
  `00000` as their length are read. Line breaks, spaces, tabs and NUL between records are skipped.
- The directory runs to the first field terminator; the data is split on field terminators, and the nth field belongs
  to the nth directory entry. Another number of fields than of entries, starts that are not five digits or that
  decrease (data in another order than the directory), a leader or a tag that is not ASCII, and indicators other than
  two characters raise `ParseError`.
- A field with a subfield delimiter is a data field, any other a control field, so local control fields such as `FMT`
  are read right. Indicators and codes are read as characters.
- Bytes are read as UTF-8, whatever leader/09 says. MARC-8 records in plain ASCII are read; others fail with a hint:
  `leader/09 says MARC-8; convert the file to UTF-8 first, e.g. yaz-marcdump -f MARC-8 -t UTF-8 -o marc -l 9=97
  in.mrc > out.mrc`.

`to_iso2709` writes the fields in record order, counts lengths in bytes and fills the leader positions it computes:
00–04 (record length), 09 (`a`, UTF-8), 10–11 (`22`), 12–16 (base address) and 20–22 (`450`). It copies the others and
never changes `record.leader`; a record without a leader gets `00000    a2200000   4500`. A field over 9,999 bytes or
a record over 99,999 bytes raises `SerializeError`; with `oversize: :allow` the numbers that do not fit are written as
all nines, which tolerant readers (this one, MARC4J's permissive reader, yaz, Perl's MARC::Record) read and strict
readers do not.

Not supported: MARC-8 beyond ASCII, fields continued over several directory entries, indicator counts other than 2 and
code lengths other than 1.

### MARC-in-JSON

[MARC-in-JSON](https://github.com/marc-in-json/marc-in-json) is `record.to_h` as JSON. `each` and `each_raw` read one
record per line (JSON Lines), as ruby-marc and Catmandu do; blank lines and byte order marks are skipped. `parse` reads
one JSON object, also over several lines. JSON arrays of records are not read: convert them with
`jq -c '.[]' in.json > out.jsonl`, and pretty-printed files with `jq -c . in.json > out.jsonl`.

The shape is strict: keys are Strings; a field is an object with one key, its tag, whose value is a String (a control
field) or an object with `"ind1"`, `"ind2"` (missing or null is `" "`) and `"subfields"`, an Array of objects with one
key, the code. Anything else, and duplicate keys, raise `ParseError` with the path to the problem: `fields[3] (245)
subfields[0]: a value must be a String, got 12`. `Record.from_h` checks Hashes the same way.

## In metacrunch jobs

### Reader

```ruby
source Metacrunch::Marc::Reader.new(params.files, normalize: :nfc), id: ->(record) { record["001"]&.value }
```

Reads what `Metacrunch::Input` reads (see metacrunch's
[Files](https://github.com/ubpb/metacrunch/blob/metacrunch-ng/docs/files.md)): one target or an Array of them —
paths, `"-"` for stdin, or IOs, which it does not close. gzip (all members, as `zcat` reads them) and tar archives
(every regular member, but not those whose names start with `.`) are detected by their content, whatever their names.

The format of each document (a file, the content of a gzip file, a tar member) is told by its first bytes, after a
byte order mark and whitespace: `<` is MARCXML, `{` MARC-in-JSON, a record length and a base address (five digits at
00–04 and at 12–16) ISO 2709. So one run reads all three formats, also from one tar archive. A document that starts
otherwise stops the run with `Metacrunch::InputError` and its first bytes (`dump.dat: is neither MARCXML, ISO 2709 nor
MARC-in-JSON: it starts with "id;title;..."`), and so does a JSON array, with a hint to convert it. An empty document
gives no records.

A record that cannot be parsed becomes a `Metacrunch::InvalidRecord` and fails under the job's failure policy; the
records after it are read. So does a record that the end of a file cuts off, e.g. after an interrupted download.
Errors of a whole input (a missing file, broken or truncated gzip or tar data) stop the run with
`Metacrunch::InputError` and the file name. The progress display shows how much of the files has been read.

### Writer

```ruby
sink Metacrunch::Marc::Writer.new(params.target, format: :iso2709)   # :xml, :iso2709 or :json
```

Writes to a path (`.gz` compresses), `"-"` for stdout, or an IO. `:xml` writes one `<collection>` with a `<record>` per
record, and its closing tag also when a run aborts, so the file stays well-formed; `:iso2709` writes the records back
to back, `:json` one record per line. `oversize: :allow` (with `:iso2709` only) writes records beyond the limits of ISO
2709 as described above. Names ending with `.zst`, `.bz2`, `.xz`, `.zip`, `.tar`, `.tar.gz` or `.tgz` are refused; see
`Metacrunch::Output`.

Records are `Record`s or, serialized in a step, Strings of the format (see Workers): a `<record>` element, an ISO 2709
record, one line of JSON. A record that the format cannot hold (a tag such as `852H` in ISO 2709, a value set in a step
with a character that XML cannot represent) stops the run with the record's position; serialized in a step, it fails
alone under the job's failure policy instead.

### Workers

`--workers` sends records between processes with `Marshal`. A parsed record costs much more to send than its String:
in `bench/parse.rb`, 42 µs per record for a parsed record and about 1 µs for its String in any format. With workers,
let the reader yield Strings, parse them in the first step and serialize in the last:

```ruby
source Metacrunch::Marc::Reader.new(params.files, parse: false)
map(name: "parse") { Metacrunch::Marc.parse(it) }
# ... steps ...
map(name: "serialize") { it.to_iso2709 }   # or it.to_xml(namespace: false), JSON.generate(it.to_h)
sink Metacrunch::Marc::Writer.new(params.target, format: :iso2709)
```

`Metacrunch::Marc.parse` reads every format, so the job does not depend on its input. `id:` then gets the String. A
job that ends in Hashes needs no serialize step. In a MARC to MARC job with cheap steps and records of 3 KB as MARCXML,
4 workers handled about 21,000 records/s when they sent records back (as many as without workers) and about 64,000
records/s when they sent MARCXML back.
````

```markdown
### Breaking changes (from metacrunch-marcxml 4.x)

- The gem is `metacrunch-marc` (`require "metacrunch/marc"`) and the namespace `Metacrunch::Marc`; MARCXML is read by
  `Metacrunch::Marc::Xml`.
- Requires Ruby 4.0 and metacrunch 5. ActiveSupport is no longer a dependency.
- `Metacrunch::Marc::Xml.parse` returns exactly one record and raises `ParseError` otherwise; `collection_mode:` and
  `Metacrunch.Marcxml(...)` are gone. `Metacrunch::Marc::Xml.each` streams the records of a collection.
- Records keep fields and subfields in document order as Arrays. `Record::Leader`, `Record::Controlfield`,
  `Record::Datafield`, `Record::Subfield`, `DatafieldSet`, `SubfieldSet` and `Document` are replaced by `Record`,
  `ControlField`, `DataField` and `Subfield`.
- `datafields(...)` and `controlfield(...)` are replaced by `fields(...)`, `field(...)`, `values(...)` and
  `value(...)`. The query strings of `Record#[]` (`"100**a,e"`) are gone; `record[tag]` returns the first field with
  that tag.
- Tags are Strings and are neither truncated nor converted: `fields(245)` raises, four-character tags work.
- The leader is a String. Blank indicators are `" "`; `:blank`, `"#"`, `"-"` and `"_"` are no longer aliases.
- Whitespace, line breaks, CDATA, repeated control fields and the order of subfields are kept as written (4.x
  collapsed whitespace and lost the order). Elements with a namespace prefix are read.
- Values must be valid UTF-8 without characters that XML 1.0 cannot represent; others raise `ParseError`.

- ISO 2709 in UTF-8: `Metacrunch::Marc::Iso2709.parse`, `.each` and `.each_raw`, and `Record#to_iso2709` with

- MARC-in-JSON, one record per line: `Metacrunch::Marc::Json.parse`, `.each` and `.each_raw`, and `Record.from_h`.
- `Metacrunch::Marc.parse` reads one record in any of the three formats.
- `Metacrunch::Marc::Reader`, a source on `Metacrunch::Input`: all three formats, told by the content of each

- `Metacrunch::Marc::Writer`, a sink on `Metacrunch::Output` with `format:` (`:xml`, `:iso2709` or `:json`), for

- Changing records: `Record#add`, `#append`, `#remove` (also with a block), `#clear`, `DataField#add`, `#remove`, deep
```
